# Prácticas React

Plantilla full stack (cliente + servidor) que uso para practicar y probar conceptos de React antes de llevarlos a proyectos reales.

## Descripción

Repositorio de práctica dividido en dos partes: un cliente en React con Vite donde pruebo componentes, hooks y patrones antes de usarlos en producción, y un servidor Node.js simple para probar la comunicación cliente-servidor end to end. Todo el código queda visible acá para poder repasarlo o reutilizarlo como punto de partida en proyectos nuevos.

## Tecnologías

`React` `Vite` `JavaScript` `Node.js`

## Estructura

- `Cliente/` — aplicación React con Vite.
- `Servidor/` — servidor Node.js de prueba.
